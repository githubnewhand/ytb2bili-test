# 视频上传连接与恢复

所有新的视频上传均使用显式直连，不继承项目下载代理或系统 HTTP_PROXY/HTTPS_PROXY。视频控制请求与分片传输均使用 HTTP/1.1，并在 TLS ALPN 中保持一致。此设置不控制电脑上的透明代理或 VPN。

每片请求总时限 2 分钟，等待响应头最多 30 秒；瞬时网络错误、HTTP 429 和 500/502/503/504 可重试，每片最多 3 次，间隔 3、6 秒。PUT 重试携带相同 uploadId/partNumber 和完整数据。界面显示当前分片、重试次数及等待服务器确认的状态。

整次文件上传失败后，重新申请上传会话并切换存储路由，依次 ws、qn、bda2，最多 3 条。切换线路需要重新上传文件。视频投稿仍在文件完整上传成功后执行。

错误提示仅匹配 HTTP status 或 API code 字段，不会因 URL、文件大小、上传 ID 包含 401/403/429/500 等数字而误判。

本机制用于减少故障造成的长期停滞，不能保证外部服务或网络永不故障。达到尝试上限时保留明确失败状态。
